# Bundled input data

The package contains only the six k3 sequences used by the final Table IV
runner. Each sequence directory contains the source images and the shared
detection/ground-truth files used by every tracker.

| Directory | Paper dataset |
|---|---|
| `uavswarm39_k3` | UAVSwarm-39 |
| `uavswarm25_k3` | UAVSwarm-25 |
| `uavswarm61_k3` | UAVSwarm-61 |
| `watercraft_k3` | Watercraft |
| `count3_k3` | Court-3 |
| `k3` | Court-2 |
