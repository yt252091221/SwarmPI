# Final reproduction scripts

- `run_table4_all_methods.py`: final six-method, six-dataset Table IV run and
  TrackEval `COMBINED` evaluation.
- `run_ablation_uavswarm25.py`: separate UAVSwarm-25 ablation run.
- `reproduce_all.py`: command dispatcher used by the repository-root
  `runall.py` entrypoint.
- `V6.py`: the Ours tracker called by the final Table IV runner.

The package intentionally omits exploratory, superseded, and unused scripts
such as `v7.py` and the earlier standalone benchmark launchers.
